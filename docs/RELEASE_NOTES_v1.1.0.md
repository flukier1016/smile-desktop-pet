# 笑笑桌宠 v1.1.0

这一版让桌宠更轻巧，也可以按自己的桌面空间自由调整。

## 新功能

- 默认大小改为原版的约 75%，不再遮挡太多内容。
- 右键桌宠或点击菜单栏图标，可在“调整大小”中选择迷你、标准或大只。
- 按住 `Option` 滚动鼠标滚轮或触控板，可连续放大、缩小。
- 自动记住所选大小，下次启动仍保持不变。

## 下载

- `SmilePet-v1.1.0-macos-universal.dmg`：推荐安装方式。
- `SmilePet-v1.1.0-macos-universal.zip`：免安装压缩包。

支持 Apple 芯片与 Intel Mac，要求 macOS 13 或更高版本。
