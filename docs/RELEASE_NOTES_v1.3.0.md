# 笑笑桌宠 v1.3.0

这一版把“功能很多”整理成了真正可用的产品：新增原生控制中心，统一管理
状态感知、OCR、尺寸和隐私；同时完整升级开源仓库和 Codex 笑笑皮肤。

## 新功能

- 原生控制中心：当前状态、前台 App、识别来源和权限一眼可见。
- 直接开关自动感知和本地 OCR。
- 直接选择 60%、75%、100% 桌宠大小和 8／15／30 秒 OCR 节奏。
- “叫她回来”跟随鼠标所在屏幕，多显示器召回更可靠。
- 气泡和状态徽章升级，缩小后仍保持清晰。
- 附带 88 帧 Codex 笑笑桌宠与配套明暗主题。

## 隐私与安全

- 继续保持无网络、无遥测、无截图或 OCR 文字存储。
- OCR 仍为主动开启，且只识别当前前台窗口。
- CI 增加凭据、私钥、原始照片和网络 API 门禁。
- 新增 CodeQL、Dependabot、私密漏洞上报和完整社区模板。
- GitHub Actions 固定到完整提交 SHA。
