# 笑笑桌宠 v1.2.0

这一版让桌宠真正“看懂你在忙什么”：前台 App 感知默认可用，还可以选择开启完全本地的屏幕 OCR。

## 新功能

- 自动识别当前前台 App，无需额外权限。
- 可选开启本地 OCR，只截取当前前台窗口并在内存中识别文字。
- 支持 23 种状态：写代码、报错抢救、胜利撒花、表格苦工、盯盘、工位服刑、写作、阅读、研究、汇报、会议、消息、邮件、设计、浏览、视频摸鱼、音乐、游戏、购物、休息、离开、深夜与陪伴待机。
- 每种状态都有独立颜色、动作、漂浮符号、道具和台词。
- 菜单新增立即识别、暂停 30 分钟、8／15／30 秒 OCR 间隔与全部状态手动预览。
- 自动识别离开超过五分钟、连续工作过久以及深夜场景。

## 隐私

- App 不联网、不上传、不含遥测。
- 默认感知只读取前台 App 的名称和标识。
- 本地 OCR 仅在用户主动开启后申请 macOS 屏幕录制权限。
- OCR 截图识别后立即释放；文字只在当前 App 会话的内存中短暂用于分类，切换 App 或关闭 OCR 即丢弃。

## 下载

- `SmilePet-v1.2.0-macos-universal.dmg`：推荐安装方式。
- `SmilePet-v1.2.0-macos-universal.zip`：免安装压缩包。

支持 Apple 芯片与 Intel Mac，要求 macOS 13 或更高版本。
