# 笑笑桌宠 v1.4.1

这一版让笑笑从桌面角色真正变成一眼可认的产品品牌：人物版图标进入 macOS App、
项目文档与官网，下载、安装和日常使用看到的是同一个笑笑。

## 人物版图标

- 新图标直接使用笑笑人物，不再只依赖文字标记。
- 保留暖奶油白、墨棕、漆红与白色花饰，和桌宠本体、控制中心及 Codex 皮肤一致。
- macOS `ICNS`、文档图标、网页导航、favicon 与分享图使用同一品牌母版。
- 新增 `Tools/build_brand_icon.py`，可以从品牌源图重复生成全部尺寸。

## 官网与隐私安全

- 新增响应式 Landing Page，覆盖场景感知、每日陪伴、隐私边界、安全工程与
  Codex 皮肤。
- 官网不设置统计、广告、Cookie 或提交表单。
- 独立 `PRIVACY.md` 补充中国大陆适用边界、网页托管边界、最小必要、权限撤回
  和本地数据清除方式。
- `SECURITY.md` 明确最新受支持版本、供应链门禁、临时签名边界与私密漏洞上报。

## 数据边界没有改变

v1.4.1 不增加 App 权限、网络请求、遥测或云端服务。默认场景感知仍只读取前台
App 名称与 Bundle ID；可选 OCR 仍只在用户主动开启后处理当前前台窗口，并在
本机内存中即时丢弃截图与文字。

## 下载

- `SmilePet-v1.4.1-macos-universal.dmg`：推荐安装。
- `SmilePet-v1.4.1-macos-universal.zip`：免安装压缩包。
- `SHA256SUMS.txt`：下载完整性校验。

支持 macOS 13 或更高版本，同时支持 Apple Silicon 和 Intel Mac。

当前安装包使用临时签名，尚未 Apple 公证。第一次启动请在 Finder 中右键
“笑笑桌宠”并选择“打开”。请只从本仓库官方 Release 下载并核验 SHA-256。
