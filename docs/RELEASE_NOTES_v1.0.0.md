# 笑笑桌宠 v1.0.0

第一只笑笑桌宠正式上桌。

## 这版有什么

- 原生 macOS 透明悬浮桌宠，不占 Dock。
- 摸头、戳身体、双击旋转、爱心和彩带动画。
- 喂零食、夸夸、今日运势、散步、暂时躲起来。
- 菜单栏召回、鼠标穿透、安静十分钟。
- 自动记住桌宠位置。
- 完全离线，不联网，不收集数据，不申请额外权限。
- 同时支持 Apple Silicon 和 Intel Mac。

## 下载哪个

- 推荐：`SmilePet-v1.0.0-macos-universal.dmg`
- 备用：`SmilePet-v1.0.0-macos-universal.zip`
- 校验：`SHA256SUMS.txt`

当前版本使用临时签名，尚未进行 Apple 公证。第一次启动请在 Finder 中右键 App，选择“打开”，再确认一次。

详细安装和排错方法见仓库中的 `MANUAL.md`。
