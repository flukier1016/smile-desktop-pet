# 性能更新：v1.5.0 源码版

## 桌宠

旧版使用 30 Hz Timer，在主线程反复重绘角色 PNG、渐变、阴影、文字、道具和粒子。
新版将角色、背景、道具、文字拆成缓存图层，交给 Core Animation 移动；气泡只在
出现、到期或场景变化时重新生成。缩放或跨屏时按目标显示分辨率更新缓存。

互动粒子共用缓存字形，同时最多 64 个（低电量模式 16 个），动画结束即移除。
隐藏、完全遮挡、锁屏和屏幕休眠会停止动画、自动感知与台词；重新可见后恢复。
安静、减少动态效果和低电量模式停止持续动画。

前台 App 切换由系统通知触发，不等待 OCR。OCR 始终只允许一个任务进行；切换
App、暂停、关闭、隐藏或撤销权限后，过期回调被丢弃。定时检查从 4 秒延长到
15 秒，低电量模式 30 秒；已离开桌面时不截屏。所有原有本地隐私边界保持不变。

### 本机对比

2026-10-15，Apple M4 Pro，macOS 26.4.1。基准使用同一角色、相同窗口尺寸、
相同编译优化，预热 1 秒后采样 8 秒。旧版基线为 `v1.4.1`（`a6154bb`）。

| 渲染场景 | 旧版进程 CPU | 新版进程 CPU | 旧版峰值 RSS | 新版峰值 RSS |
| --- | ---: | ---: | ---: | ---: |
| 持续陪伴 | 6.61% | 0.30% | 78.4 MiB | 54.9 MiB |
| 写代码场景 | 6.72% | 0.44% | 79.8 MiB | 53.6 MiB |
| 每 0.5 秒触发一次庆祝 | 46.67% | 0.70% | 83.4 MiB | 55.5 MiB |
| 窗口隐藏 | 6.32% | 0.02% | 77.1 MiB | 52.0 MiB |

CPU 按单核 100% 计算。这是隔离渲染基准，未启动自动感知或 OCR，也不读取或
修改用户的陪伴数据。结果不包含 WindowServer/GPU 开销，不能等同于整机耗电
下降比例；短窗口采样会受系统负载影响，实际完整 App 占用还包括感知和互动。

复现（需要可用的 macOS 图形会话）：

```bash
./scripts/benchmark.sh v1.4.1 8
```

原始 JSON 写入 `.build/benchmark-baseline.jsonl` 与
`.build/benchmark-current.jsonl`。每条记录同时输出窗口可见／遮挡状态，避免把
被遮挡的动画当作可见动画成绩。

## 官网

- React 只作为开发和构建时的页面模板。生产 HTML 已包含完整产品内容，客户端
  不加载 React、不做整页 hydration。
- 场景切换只更新相关文字、图标和颜色，鼠标位移合并到一次 requestAnimationFrame。
- 88 帧精灵通过整张纹理的位移动画播放，移除每帧 React 状态更新；接近可见区域
  才下载图集，离屏或后台标签页暂停。
- 区域动画按可见性暂停，减少动态效果时停用；手机减少模糊、阴影和轨道动画。
- HTML、JS、CSS 的原文及 Brotli/gzip 版本在服务启动时缓存，请求时不再逐次
  stat 或压缩；保留已有 Railway CDN 缓存头。

旧官网客户端脚本为 **218,312 字节**，新版为 **5,385 字节**，减少约 **97.5%**；
gzip 后约从 68.5 KB 降至 2.6 KB。预渲染 HTML 从约 1.5 KB 增加至约 33.8 KB，
以可立即显示的产品内容替代空容器。构建后的测试设置 16 KiB
JavaScript 预算，同时验证预渲染内容、编码质量协商、HEAD、ETag、并发响应和路径处理。
这属于资源量和执行路径的改进，不代表所有网络环境下都有固定加载时间或帧率。
