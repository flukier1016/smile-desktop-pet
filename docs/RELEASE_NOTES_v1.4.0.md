# 笑笑桌宠 v1.4.0

这一版把“好玩的互动”放回产品正中央。控制中心不再只是设置面板，而是每天
都值得打开一次的陪伴主页：摸摸、喂食、夸夸、抽签，慢慢把笑笑养成你的
“灵魂工友”。

## 每日陪伴

- 新增摸摸、喂食、夸夸、今日签 4 项每日任务。
- 每项首次完成会点亮进度并获得额外经验。
- 完成当日 4 项后触发奖励、庆祝动画和连续陪伴天数。
- 新增 5 个关系等级：初见搭子、熟悉同桌、默契拍档、桌面知己、灵魂工友。
- 戳一下、散步和庆祝也会积累互动与经验。
- 第一次启动会直接打开陪伴页，不再把核心玩法藏在右键菜单里。

## 界面与可访问性

- 控制中心升级为“陪伴／设置”双页结构。
- 陪伴页集中展示等级、经验、连续天数和今日进度。
- 6 个直接互动按钮统一为不小于 44 点的点击目标。
- 强化状态标签、底部提示和进度条的对比度。
- 新增键盘焦点、VoiceOver 名称／值／操作语义。
- 开启 macOS“减少动态效果”后，自动停用弹跳与粒子动画。

## 隐私与质量

- 成长数据只保存在本机 `UserDefaults`，不需要账号，不联网，不同步。
- 不保存互动台词、前台 App 历史、窗口标题、截图或 OCR 文字。
- 新增 14 个陪伴进度自动化测试；连同场景分类共 37 个测试。
- 继续提供 Apple Silicon 与 Intel 通用二进制、安全检查和 CodeQL。

## Codex 笑笑皮肤

仓库附带的 Codex 皮肤已与桌宠统一为暖奶油白、墨棕、漆红和场景青配色，
包含 88 帧原生自定义桌宠与 Rosé Pine 明暗代码主题。安装过程不修改 Codex
官方 App 包，并会先保存可恢复的配置备份。
