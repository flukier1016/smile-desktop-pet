# Security

## Supported version

Only the latest release is supported.

## Reporting

Please do not publish sensitive information in a public Issue. For ordinary
bugs that contain no private data, use the repository Issue tracker.

The app is intentionally offline and requests no camera, microphone, file,
screen-recording, contacts, location, or network permission. A future change
that adds networking or telemetry must be disclosed in `PRIVACY.md` and the
corresponding release notes.
